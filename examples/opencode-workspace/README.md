# OpenCode Workspace Example

This example will eventually show how to configure AgentDeck for an OpenCode-driven workspace.

Planned panes:

- `TERM-01`: OpenCode agent.
- `TERM-02`: development server.
- `TERM-03`: test watcher.
- `TERM-04`: manual shell.

Agents should use the AgentDeck MCP server for shared todos, notes, docs, and memory.
